# update_cell_conf.sh — смена сети в конфигах ячеек Exadata

> **Демонстрационные (синтетические) данные.** Этот репозиторий содержит только
> вымышленные hostname/IP/MAC. Все значения взяты из зарезервированных
> документационных диапазонов (RFC 5737, RFC 2606, RFC 7042) и **не являются**
> реальной инфраструктурой.

Скрипт `update_cell_conf.sh` меняет management-сеть (`eth0`), настройки ILOM, DNS,
NTP и таймзону в XML-конфигурациях ячеек Exadata (`cell.conf`). Источник новых
значений — база preconf Oracle OneCommand (CSV). Исходные конфиги не изменяются:
результат всегда пишется в отдельный файл с суффиксом `_new.conf`.

Подменяются ровно эти поля, остальное сохраняется дословно:

| Что меняется в конфиге | Откуда берётся |
|---|---|
| `<Interfaces>` блока `eth0`: `Gateway`, `IP_address`, `Netmask` | management-сеть строки базы |
| корневые `<Nameservers>` (2 тега) | DNS из базы, первые два адреса |
| корневые `<Ntp_servers>` (2 тега) | NTP из базы, первые два адреса |
| `<Timezone>` и `<ILOM_Timezone>` | таймзона из базы |
| `<ilom>`: `ILOM_Gateway`, `ILOM_IP_address`, `ILOM_Netmask` | сеть ILOM строки базы |
| `<ilom>`: `ILOM_Nameserver` | DNS ILOM, весь список через запятую |
| `<ilom>`: `ILOM_First/Second_NTP_server` | NTP ILOM |

## Состав каталога

| Файл | Назначение |
|---|---|
| `update_cell_conf.sh` | сам скрипт (bash + awk; зависимостей нет) |
| `R3_preconf_ex9s.csv` | база preconf (идентичны) |
| `cell_conf/cell_exacellNN.conf` | исходные конфиги ячеек (NN = 01..40) |
| `cell_conf/cell_exacellNN_new.conf` | результат работы скрипта (уже сгенерированы) |
| `cell_conf/sum.md5` | контрольные суммы исходных конфигов |

## Синтетическая схема адресов

| Параметр | Значение | Диапазон |
|---|---|---|
| Имена ячеек | `exacell01..40` | нейтральные |
| Домен | `example.test` | RFC 2606 |
| Management (eth0) | `192.0.2.NN+20` / `255.255.255.0` / gw `.254` | TEST-NET-1, RFC 5737 |
| ILOM | `192.0.2.NN+36` / `255.255.255.0` / gw `.254` | TEST-NET-1, RFC 5737 |
| Private (re0/re1) | `198.51.100.x` / `255.255.252.0` | TEST-NET-2, RFC 5737 |
| DNS корня и ILOM | `203.0.113.10`, `203.0.113.11` | TEST-NET-3, RFC 5737 |
| NTP корня и ILOM | `203.0.113.20`, `203.0.113.21` | TEST-NET-3, RFC 5737 |
| MAC | `00:00:5e:00:53:NN` | OUI IANA doc, RFC 7042 |
| Таймзона | `Europe/Moscow` | — |

У ячейки `exacell27` нет тега `<Pkeyconfigured>` (75 строк вместо 76) — вариант,
который скрипт тоже корректно обрабатывает.

## Запуск

```bash
./update_cell_conf.sh                                      # только справка
./update_cell_conf.sh -dry R3_preconf_ex9s.csv cell_conf   # контрольный прогон
./update_cell_conf.sh    R3_preconf_ex9s.csv cell_conf     # записать _new.conf
```

На синтетическом наборе прогон завершается без ошибок и предупреждений:
`Итого: обработано 14, пропущено 2, предупреждений 0, ошибок 0`.
Контроль исходников — `cd cell_conf && md5sum -c sum.md5`.

Подробная документация поведения скрипта (опции, логика, самоконтроль, раскладка
по хостам) описана в комментариях к коду внутри `update_cell_conf.sh`.
